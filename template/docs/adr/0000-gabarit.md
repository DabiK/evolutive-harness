# NNNN — La décision, dite en une phrase

- Date : AAAA-MM-JJ
- Ticket : `docs/travail/tickets/NNN-slug.md`
- Statut : acceptée

## Contexte

Le problème tel qu'il se posait, avec les faits qui le montrent (mesure, constat, `chemin:ligne`).
Trois à six lignes.

## Décision

Ce qui a été choisi, au présent. Ce que le code fait désormais et où.

## Alternatives écartées

Une ligne par alternative réellement envisagée, avec la raison du rejet.

## Conséquences

Ce que la décision rend plus simple, ce qu'elle rend plus difficile, ce qu'elle laisse ouvert.

## Protégée par

Les tests ou contrôles qui échouent si la décision est défaite.
